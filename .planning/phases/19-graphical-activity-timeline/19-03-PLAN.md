Create `packages/frontend/src/components/timeline/MediaEventList.tsx`:

1. Define types:
```typescript
interface MediaEvent {
  type: 'grab' | 'download_complete' | 'health_issue' | 'health_restored'
  summary: string
  service: string
  timestamp: string
}
```

2. Implement `parseEventFromLog(entry: LogEntry): MediaEvent | null`:
   - Try JSON.parse on `entry.payload ?? '{}'`
   - Check `eventCategory` field: 'grab' -> type grab, summary `${entry.service.toUpperCase()} GRAB - ${title ?? 'Unknown'}`
   - 'download_complete' -> type download_complete, summary `${entry.service.toUpperCase()} DOWNLOAD - ${title ?? 'Unknown'}`
   - 'health_issue' -> type health_issue, summary `SERVICE DOWN - ${entry.service}`
   - 'health_restored' -> type health_restored, summary `SERVICE RESTORED - ${entry.service}`
   - Also check `entry.message` for patterns like "now offline" / "back online" for health events that may not have eventCategory in payload
   - Return null if no match (non-event log entries)
   - Wrap in try/catch, return null on parse failure

3. Component `MediaEventList` props: `{ window: TimeWindow }` (to know how far back to fetch)
   - State: `events: MediaEvent[]`, `loading: boolean`, `serviceFilter: string` (default 'all'), `typeFilter: string` (default 'all')
   - On mount and when `window` changes: fetch from `/api/logs?limit=1000&offset=0&level=all&service=all`, parse each entry through `parseEventFromLog`, filter out nulls, filter by time window (only keep events within the window period), store in state
   - Client-side filtering: apply serviceFilter and typeFilter to events array
   - Unique services extracted from events for the service dropdown options
   - Event type options: ALL, GRAB, DOWNLOAD, SERVICE DOWN, SERVICE RESTORED

4. Render:
   - Section heading: `MEDIA + SERVICE EVENTS` (18px, amber, 600 weight, 0.08em spacing)
   - Filter bar: service dropdown + event-type dropdown (same `selectStyle` pattern as LogsPage, min-height 44px on iPhone via useViewport)
   - Scrollable list container with max-height per viewport (kiosk: `calc(100vh - 420px)`, iPhone portrait: `calc(100dvh - 380px)`, landscape: `calc(100dvh - 300px)`)
   - Each event row: flex row with gap 10px, alternating bg per LogsPage pattern
     - Type indicator dot: 8px circle, border-radius 50%, colors: grab=`var(--cockpit-purple)` (#8B5CF6), download_complete=`var(--cockpit-amber)`, health_issue=`var(--cockpit-red)`, health_restored=`var(--cockpit-green)`
     - Event type tag: reuse ServiceTag pattern (amber bg + border)
     - Summary text: 15px body, `var(--text-offwhite)`, flex 1, overflow ellipsis
     - Timestamp: 12px, right-aligned, `var(--text-offwhite)` at 70% opacity
   - Empty state: "NO EVENTS" heading + "No events match the current filter." body per UI-SPEC copywriting
   - Loading state: "LOADING..." per LogsPage pattern
